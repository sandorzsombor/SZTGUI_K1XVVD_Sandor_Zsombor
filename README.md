A feladat egy asztali alkalmazás önálló tervezése és fejlesztése WPF keretrendszerben, a feladat témája tetszőleges.
Elvárások:
    -Legyen benne legalább két ablak, amik között működjön az adatáramlás valamilyen formában (pl. egy editor window). 
    Vagy egy ablak, de abban legyen több funkció, akár tabokkal elkülönítve (mint egy böngészőben a megnyitott lapok közötti váltás), 
    vagy az ablakban más tartalom jelenjen meg (mint amikor tovább navigálunk egy weboldalon). 
    -A tárgyban foglalt technikák alkalmazva legyenek: adatkötéssel legyen minden megjelenítve, 
    illetve pl. használjuk ki a továbbított események adta lehetőségeket (20 db hasonló funkcionalitású gombnak nem feltétlenül kell 20 eseménykezelő metódus).
    -Az alkalmazás rétegezve legyen felépítve! MVVM nem kötelező, azt rátok bízom. 
    -A fejlesztést git verziókezelő használatával valósítsátok meg, a végén kérek majd megosztást GitHubon.

A megoldásom egy focis, csapatépítős alkalmazás lett, ahol balklikkel tudjuk, az adott pozícióra beilleszteni az adott játékost, 
amennyiben van ilyen a csapatunkban. Ha nincs hibaüzenetet dob és hozzá kell adnunk egyet. Természetesen egy játékost egyszer használhatunk fel és
csak a saját pozícióján jelenik meg, ott tudjuk játszatni.
